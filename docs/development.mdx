## Testing Strategy

RAGRoute utilizes pytest with asynchronous test runners and fixture mocks to test agents deterministically without incurring API billing or network dependencies during CI.

### Running Test Suites

```bash
# Run unit tests
uv run pytest tests/unit_tests

# Run integration tests
uv run pytest tests/integration_tests

# Run all test suites
uv run pytest tests/
```

### Mocking GenAI Responses

Fixtures in `tests/conftest.py` provide recorded responses from Gemini:
- `fake_classifier_response`: Parses mock classification payloads (`tests/data/classifier.raw.txt`).
- `fake_synth_response`: Mocks function calling responses (`tests/data/synthesiser.raw.txt`).

These fixtures allow testing node transitions, State updates, and function calling configurations independently from live model endpoints.
