# Installation & Setup

This guide details how to install dependencies, set up PostgreSQL with the `vector` extension, and launch RAGRoute.

## Prerequisites

- **Python**: 3.10 or higher (Python 3.11+ recommended)
- **Node.js**: 20.19+ (if running `docs7 dev` locally)
- **PostgreSQL**: Version 15+ with the `pgvector` extension installed
- **Google Gemini API Key**: Access to Gemini models (`gemini-2.5-flash-lite`, `gemini-2.5-flash`, and `text-embedding-004`)

## Environment Setup

Clone the repository and install dependencies using `uv` or `pip`:

```bash
# Clone the repository
git clone https://github.com/your-username/RAGRoute.git
cd RAGRoute

# Using uv (recommended)
uv sync

# Or using pip
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

## Environment Configuration

Configure your environment variables in a `.env` file at the repository root:

```env
# Gemini API credentials
GEMINI_API_KEY=your_gemini_api_key_here

# PostgreSQL connection string
DB_DSN=postgres://postgres:password@localhost:5432/wine_review_text_vector_search_db
```

## Database Initialization

RAGRoute expects a PostgreSQL database with `vector` extension and table `wines_3`:

```sql
-- Enable pgvector extension
CREATE EXTENSION IF NOT EXISTS vector;

-- Create wines table with full-text search and vector columns
CREATE TABLE IF NOT EXISTS wines_3 (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    description TEXT NOT NULL,
    tsv tsvector GENERATED ALWAYS AS (
        setweight(to_tsvector('english', coalesce(title, '')), 'A') ||
        setweight(to_tsvector('english', coalesce(description, '')), 'B')
    ) STORED,
    embedding VECTOR(256)
);

-- Create HNSW index for cosine similarity
CREATE INDEX IF NOT EXISTS wines_3_embedding_hnsw_idx 
ON wines_3 USING hnsw (embedding vector_cosine_ops);
```

To ingest wine reviews from CSV:

```bash
python -m src.rag_agent.db.batch_insert
```

## Running the Agent

Start the agent server using the LangGraph CLI:

```bash
langgraph dev
```

The LangGraph API server will start and bind to `http://localhost:2024` with the agent graph declared in `langgraph.json`.
